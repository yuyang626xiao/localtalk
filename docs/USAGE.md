# 使用说明（详版）

> 快速上手见根目录 [README.md](../README.md)；本文是所有面板与参数的完整语义。

## 会话与模式

- **开始会话**（底部中央，Sokuji 同款模型）：点一下加载引擎并**常开麦克风**（首次加载
  模型较慢）；再点变「停止会话」。两种语音模式都以它为前提。
- **按住说话**模式：会话开启后，按住「按住说话」按钮（或空格）说话，松手：
  识别字幕 → 翻译 → 自动朗读译文。麦克风常开，按住只是**分段门控**；按键瞬间若 VAD
  已在说话（开口早于按键/噪声先触发），会立即补发 start 标记接住这段语音；松手后
  若整段没有任何结果，状态栏明说「未识别到语音」而不是卡在识别中。
- **自动（VAD）模式**：会话开启后语音活动检测自动断句，说完停顿（默认 1.4s，Sokuji
  同款）即自动识别翻译，适合连续对话。断句灵敏度、判停时长、最短语音在「VAD 断句」
  面板里调。注意：离线 ASR 模型**没有中间 partial**，只在 end 标记后整段转写一次；
  判停调太短会把句子切碎成无上下文片段，准确率大幅下降。
- **通道模式**（控制条「我 / 对方 / 两者」，Sokuji 同款）：**我** = 只翻自己的话（麦克风）；
  **对方** = 只翻对方的声音——选一个对方音频源（如 CABLE Output / 立体声混音），反方向
  识别+翻译，在对话流以琥珀色「对方」行显示（不朗读）；**两者** = 双链路并行，
  各跑一个 sidecar 进程，显存叠加。语音模式（按住/自动）只作用于「我」链路，
  「对方」链路始终 VAD 自动断句。

## 音频设备面板（Sokuji 同款语义与样式）

- 麦克风/扬声器是**列表式选择器**——首行系统默认、选中行绿色高亮、环回/虚拟设备带
  ⚠ 提示（可选但有回声风险）、区块头部图标 + ? 帮助气泡 + ↻ 刷新（扫描时旋转），
  热插拔自动跟随。
- **精简列表**勾选可隐藏 Chromium 的 `Default - / Communications -` 角色别名行
  （当前正选中的别名行会保留，不会丢选择）。
- 噪声抑制三档——**关闭**（仅浏览器内置 APM）/ **标准**（RNNoise worklet，轻量）/
  **增强**（GTCRN 神经网络 worker，效果更好、CPU 略高，加载失败自动降级标准）。
- **原声直通**把自己的麦克风声音 30% 实时送到所选扬声器（建议戴耳机）。
- 降噪/直通/扬声器即时生效，换麦克风会重建会话。通道模式含「对方」时多出
  **对方音频源**区块——若它拾取的是本机全部播放声，译文朗读会被录回去形成自我循环，
  建议把会议声音单独路由到一条虚拟线缆。

## 音色克隆（语音合成设置）

- 支持克隆的 TTS 家族（MOSS-TTS-Nano、Qwen3-TTS、OmniVoice、IndexTTS2、VoxCPM 等）
  可**录一段你的声音**（3-20s，OmniVoice 上限 8s，自动峰值归一 + 静音/过短/过长校验）
  或**导入音频文件**作为参考音色；列表点选即切换，会话中换音色即时生效。
- Qwen3-TTS/OmniVoice 是**克隆制**（无内置音色，必须配参考音频，Qwen3-TTS 还要填
  音频文字稿），选了这类模型面板自动进入克隆模式。
- 「试听」按钮**无需开始会话**即可合成一句目标语言样例（独立预览通道；会话开着时
  自动复用会话引擎）；每行 ▶ 按钮直接回放原始录音（纯本地，用来确认录清楚了没有）。
- 录音数据存 IndexedDB（`localtalk-native-voices`），「释放引擎显存」同时释放预览引擎。

## 其余面板

- **底部控制条**（Sokuji 布局）：左簇 = 状态点 + 通道模式快切 + 麦克风电平/朗读电平
  色块（AnalyserNode RMS，rAF 直写 DOM）；中央 = 开始会话绿药丸（会话中变深色
  「停止会话」），按住说话模式下旁边多一个「按住说话」门控按钮（会话未开时置灰，
  「对方」模式下隐藏）；右 = 引擎状态文字 + 方向标签。**自适应**：主区窄于 720px
  时折成两行，≤700px 隐藏方向标签——任意面板宽度都不会重叠。
- **左栏**：语言方向（⇄ 一键互换，**每个方向记住自己的三段模型**）、翻译提示词
  （快捷=默认模板预览 / 高级=自定义系统指令，下一句即时生效；个别模型如
  TranslateGemma 不支持则自动禁用）、TTS 语速与音色、朗读/音量、存储管理
  （已用 MB、逐个删除模型）、引擎状态（各段设备/耗时/实测显存）。
- **对话流工具栏**：两者 → 译文 → 原文 → 关闭 四态显示切换、字号 A↓/A↑、
  折叠消息头、导出（txt/json 下载或复制剪贴板，可选原文/译文范围）、清空。
- 顶栏实时显示**预估 VRAM/RAM**（按所选卡的档位与显存排行程），加载后换成实测值。
- **「释放引擎显存」**关闭全部会话连接，按 sidecar 契约把模型从显存/内存中卸下。
- 设置全部持久化（localStorage），重启保留；模型/语言/VAD 改动会自动重建会话。
